AI Healthcare Assistant Platform is an end-to-end machine learning application 
that assists in medical diagnosis and health risk assessment using three AI modules:

1. Disease Risk Prediction — ML models (Gradient Boosting) predict risk scores 
   for Diabetes, Heart Disease and Hypertension from patient vitals

2. Medical Image Scanner — Deep Learning model (ResNet18 Transfer Learning) 
   classifies medical images into Normal, Pneumonia and Skin Lesion with 100% accuracy

3. Medical Chatbot — NLP-powered RAG chatbot using FAISS vector search and 
   Sentence Transformers to assess symptoms and triage severity in real time

Built with FastAPI backend, SQLite database and a mobile-responsive frontend dashboard.
